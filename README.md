# 贵格会：历史、神学与实践

中文静态研究型教育网站，面向第一次接触 Quaker / Religious Society of Friends 的读者，也面向希望继续追索历史、神学、人物与实践脉络的中文读者。

## 三层阅读结构

### 第一层：首页入门
- `index.html`：历史时间线、神学核心、实践、人物、现代分支与阅读入口

### 重点模块：贵格会灵修实践
- `spiritual-practices.html`：以 FGC 十六项 Spiritual Practices 为入口，用「静默—关系—辨识—召命」四条轴线重组，支持互动筛选与折叠阅读
- `practice.html`：灵修实践子专题，深入静默敬拜、口头服事、敬拜式事务聚会与澄心会
- `glossary.html`：已补入 Queries、Ministry、Calling、Spiritual Gifts、Faithfulness、Worship Sharing、Covenant Group 等术语

### 第二层：专题深化
- `origins.html`：17世纪英国、Seekers、1652 与运动成形
- `genealogy.html`：思想谱系；区分历史传承、结构相似与后来的跨传统对话
- `inner-light.html`：Inward Light / Light Within / Inward Christ
- `fox-barclay.html`：George Fox 的经验语言与 Robert Barclay 的神学表达
- `schisms.html`：1827、1845 以后北美贵格会分裂
- `glossary.html`：中文术语词典，支持即时搜索
- `readings.html`：按问题组织的阅读路径

### 第三层：研究关系
- `people.html`：人物谱系——不是伟人排名，而是问题如何被一代代重新回答
- `timeline.html`：互动历史时间轴，可按历史 / 神学 / 组织 / 社会见证筛选
- `theology-map.html`：互动神学概念图，连接内在之光、启示、基督、圣经、敬拜、辨识、共同体与见证

## 编辑原则

- 中文原生表达，不逐字翻译。
- 区分“资料明确支持”“本站解释性概括”“史学上的不确定”。
- 不把相似性误写成直接历史传承。
- 不把贵格会简化为 SPICES 价值口号。
- 不把“内在之光”简化为“相信自己的直觉”。
- 不把贵格会的“内在”写成纯个人主义；始终连接共同体辨识与现实行动。
- 对 Brinton 等20世纪中叶作者带有时代局限的跨宗教概括，保留其启发性框架，但明确标示需要修正之处。
- 人物页不做“伟人史”，而围绕人物正在回答的核心问题组织。
- 标题优先按完整语义单位换行，避免出现半句或单字孤悬。
